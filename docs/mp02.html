Identifying Environmentally Responsible US Public Transit Systems

Green Transit Alliance (GTA) will be looking into the “greenest” public transit agencies. Each year, GTA awards prizes to the small, medium, and large transit agencies that score the highest on the GTA Value Index (GTA VI). The GTA VI estimates the effective emissions reductions achieved by each agency, using a combination of:

  • Local ridership data (both number and distance); and
  • Emissions estimates of public transit vehicles (either direct tailpipe emissions or upstream emissions from electrical generation)

By comparing these to the tailpipe emissions that would have occured if all riders had instead driven to their destination, the VI identifies the most valuable public transit agencies in the country.

has_table <- function(path){
  if(!file_exists(path) || file_size(path) == 0) return(FALSE)
  tryCatch(
    !inherits(read_html(path) |> html_element("table"), "xml_missing"),
    error = function(e) FALSE
  )
}

get_eia_sep <- function(state, abbr){
  state_formatted <- str_to_lower(state) |> str_replace_all("\\s", "")

  dir_name  <- path("data", "mp02")
  file_name <- path(dir_name, state_formatted)
  dir_create(dir_name, recurse = TRUE)

  if(!has_table(file_name)){
    if(file_exists(file_name)) file_delete(file_name)   # clear bad cache

    request("https://www.eia.gov") |>
      req_url_path("electricity", "state", state_formatted) |>
      req_headers(`User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |>
      req_retry(max_tries = 4) |>
      req_throttle(rate = 1) |>              # be polite, avoid being blocked
      req_perform(path = file_name) |>
      resp_check_status()

    if(!has_table(file_name)){
      file_delete(file_name)
      stop("No table found on EIA page for: ", state)
    }
  }

  TABLE <- read_html(file_name) |>
    html_element("table") |>
    html_table() |>
    mutate(Item = str_to_lower(Item))

  if("U.S. rank" %in% colnames(TABLE)){
    TABLE <- TABLE |> rename(Rank = `U.S. rank`)
  }

  get_val <- function(item){
    TABLE |> filter(Item == item) |> pull(Value) |>
      str_replace_all(",", "") |> as.numeric()
  }

  data.frame(
    CO2_MWh                = get_val("carbon dioxide (lbs/mwh)"),
    primary_source         = TABLE |> filter(Item == "primary energy source") |> pull(Rank),
    electricity_price_MWh  = get_val("average retail price (cents/kwh)") * 10, # cents/kWh -> $/MWh
    generation_MWh         = get_val("net generation (megawatthours)"),
    state                  = state,
    abbreviation           = abbr
  )
}

EIA_SEP_REPORT <- map2(state.name, state.abb, get_eia_sep) |> list_rbind()

load_ntd_energy <- function(){
  library(readxl)
  library(httr2)
  library(tidyverse)
  library(fs)
  
  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse=TRUE)

  NTD_ENERGY_FILE <- fs::path(DATA_DIR, "2025_ntd_energy.xlsx")

  if(!fs::file_exists(NTD_ENERGY_FILE)){
    library(httr2)
  
    request("https://www.transit.dot.gov/") |>
      req_url_path("sites",
                   "fta.dot.gov",
                   "files",
                   "2026-09",
                   "2025 Energy Consumption_260806.xlsx") |> 
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |> 
      req_perform(NTD_ENERGY_FILE)
  }
  
  if(file.info(NTD_ENERGY_FILE)$size < 1e4){
        cat("I was unable to download the NTD Energy File. Please try again.\n")
        stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
    }

  to_numeric_fill_0 <- function(x){
    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |> 
    select(-c(`Reporter Type`, 
              `Reporting Module`, 
              `Gallons of Other Fuel`, 
              `Other Fuel Description`)) |>
    mutate(across(-c(`Agency Name`, 
                     `Mode`,
                     `TOS`), 
                  to_numeric_fill_0)) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(across(where(is.numeric), sum), 
              .groups = "keep") |>
    mutate(ENERGY = sum(c_across(c(where(is.numeric))))) |>
    filter(ENERGY > 0) |>
    select(-ENERGY) |>
    ungroup()
}

load_ntd_service <- function(){

  recode_values(x,

#### About the GTA Value Index (GTA VI)

The Green Transit Alliance Value Index (GTA VI) evaluates public transit agencies across the United States to measure their net environmental contribution. Rather than ranking agencies purely by size or passenger volume, the GTA VI measures operational efficiency by standardizing transit usage against comprehensive carbon accounting:

- Unlinked Passenger Trips (UPT): The total number of individual boardings across a transit system.

- Passenger Miles Traveled (PMT): The cumulative distance traveled by all passengers, accurately capturing long-distance commuter rail efficiency alongside dense city bus routes.

- Full-Lifecycle Emissions Accounting: Direct tailpipe emissions from diesel, gasoline, CNG, and bio-diesel fuels combined with indirect upstream power grid emissions generated by electrified rail and trolleybus networks (evaluated via state EIA grid carbon profiles).

By contrasting actual operational carbon footprints against a private passenger vehicle baseline, the GTA VI identifies transit agencies delivering maximum climate value per mile.


#### The Greenest Transit Agency (Overall)

Many are interested in knowing who won the Greenest Transit Agency award, but how do we measure it?

Well, the GTA VI evaluates the lbs of CO2 emitted per Passenger Mile Traveled (PMT) across high-capacity transit providers. PMT serves as the ultimate equalizer in transit analytics since it measures environmental cost per unit of actual passenger distance moved, preventing high-density metro rail systems and long-haul regional networks from being penalized for size.
